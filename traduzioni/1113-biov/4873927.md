# Biovision_Hierarchy

*[Voce originale su Wikipedia](https://en.wikipedia.org/wiki/Biovision_Hierarchy)*

**BioVision Hierarchy** (BVH) è un formato di file utilizzato per archiviare i dati di motion capture. È stato sviluppato da BioVision, un'azienda che è stata successivamente acquisita da Motion analysis Corporation. Il formato consiste in una struttura gerarchica di giunti, con ogni giunto che contiene dati di rotazione e traslazione. I file BVH sono ampiamente utilizzati nelle industrie del cinema, dei videogiochi e dell'animazione.

## Storia e Sviluppo

La storia e lo sviluppo del formato di file BVH risalgono agli anni '90. Fu originariamente sviluppato come un formato proprietario per i sistemi di motion capture di BioVision, ma successivamente è stato adottato da altri sistemi di motion capture, come Vicon e OptiTrack. Nei primi tempi, i file BVH venivano creatI per modelli specifici e dovevano essere rielaborati per diversi modelli. Tuttavia, con l'aumentare dell'uso di BVH, sono stati creatI e utilizzati modelli più standardizzati su diversi sistemi.

Lo sviluppo del formato di file BVH ha rappresentato una pietra miliare significativa nell'animazione 3D e nel motion capture. Prima di BVH, i dati di movimento venivano registrati su carta o inseriti manualmente in un computer. BVH ha permesso la cattura e la registrazione automatica dei dati di movimento, rendendo più facile ed efficiente la creazione di animazioni realistiche.

Oggi, BVH rimane un formato di file ampiamente utilizzato per i dati di motion capture ed è supportato da molti pacchetti software di animazione, come Maya e Blender di Autodesk. È diventato uno strumento essenziale nell'industria dell'animazione, in particolare per creare animazioni realistiche e vivide per film e videogiochi.

## Confronto con altri formati di file

### Filmbox (FBX)

* I file BVH sono spesso utilizzati insieme a applicazioni software che supportano il formato, tra cui Blender, Maya e MotionBuilder.
* I file FBX sono compatibili con una vasta gamma di applicazioni software, inclusi i prodotti Autodesk, Unity e Unreal Engine.
* I file BVH sono limitati alla cattura dei dati di animazione e non includono altre informazioni sulla scena.
* I file FBX offrono una gamma più ampia di funzionalità di animazione, inclusi il supporto per eventi di animazione, diversi tracciati di animazione e curve.
* I file BVH sono comparativamente più piccoli rispetto ai file FBX.
* FBX offre maggiore controllo e flessibilità a scapito di una complessità e di una dimensione del file maggiori.
